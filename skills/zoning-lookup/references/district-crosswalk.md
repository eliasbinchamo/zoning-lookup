# District-name crosswalk

Users describe districts in plain words; codes use local abbreviations. Always match on the code's own district list and **purpose statement**. These patterns are common starting points, not rules — the same abbreviation means different things in different places (e.g. `C-2` is "General Commercial" in one city and "Neighborhood Commercial" in another).

| User says | Common code labels | Confirm by purpose statement mentioning |
|---|---|---|
| General Commercial | GC, CG, C-G, C-2, C-3, B-2, B-3, BG, GB, CB (Community Business) | "wide range of retail, service, office", community/regional-serving, auto-accessible |
| Neighborhood Commercial | NC, CN, C-1, B-1, LB (Local Business), NB | small-scale, serves adjacent neighborhoods, size caps |
| Highway Commercial | HC, CH, C-H, C-4, B-4, HB, SC (Service Commercial) | arterial/highway frontage, auto-oriented, travel services |
| Central Business / Downtown | CBD, D, DT, C-5, B-5, DC, MU-D | downtown, zero setbacks, form-based standards |
| Office / Professional | O, OP, O-1, PO, OI (Office-Institutional) | offices, limited retail |
| Mixed Use | MU, MX, MXD, CMU, TC (Town Center) | vertical/horizontal mix, residential allowed |
| Light Industrial | IL, LI, M-1, I-1, BP (Business Park) | light manufacturing, warehousing, limited nuisance |
| Planned (PUD/PD) | PUD, PD, GPD, PCD | standards set by an approved plan — the base code alone is insufficient; the specific PD ordinance/plan governs |

## Matching procedure

1. Open the "Zoning districts established" / "Districts" section and list every business/commercial district with its name.
2. Exact-name match wins ("General commercial (GC) district").
3. No exact match → compare purpose statements and the scale of uses each allows; pick the closest and explain the choice.
4. Code was rewritten recently → old district names may survive in the user's documents (listing sheets, old surveys). Look for a conversion/transition table ("former district → new district"), usually in the general provisions or the ordinance adopting the rewrite.
5. If the parcel is in a PD/PUD, say that the PD approval governs and the base-district numbers may not apply.

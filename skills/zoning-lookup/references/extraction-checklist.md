# Extraction checklist: where each requirement lives and what trips people up

Most modern codes put each requirement in a different article. A district section typically has the dimensional table and cross-references; uses and parking are elsewhere. Follow the cross-reference table at the end of the district section if there is one.

## 1. Permitted uses
- **Where:** "Use regulations", "Permitted use table", "Table of uses", "Use matrix". Sometimes split by classification (residential/institutional/commercial/industrial tables) — check **all** of them for the district column, plus accessory and temporary use tables.
- **Capture:** the legend (P / C / S / SE / SUP / CUP / A / T / blank) with each letter's approval process and section; the list of by-right commercial uses; uses needing discretionary approval; notable prohibited uses relevant to commercial buyers (e.g. warehouse, light manufacturing, heavy vehicle repair, residential on ground floor).
- **Traps:** use-specific standard references in the last column (distance separations, size caps, hours); "unlisted use" interpretation clause; residential allowed only in specific configurations (e.g. upper floors only); alcohol uses routed to a separate permit.
- **Presenting:** group by category; don't paste 100 rows — list by-right uses in compact category lines, then all C/S uses, then key prohibitions.

## 2. Building height
- **Where:** district dimensional table; general "height exceptions" section (parapets, mechanical, towers); neighborhood compatibility / transitional height near residential.
- **Capture:** max feet and/or stories; measurement method if unusual; residential-adjacency step-downs.

## 3. Setbacks
- **Where:** district dimensional table + footnotes; "neighborhood compatibility" or "transitional" standards; landscape **buffer** yards (often larger than the setback when abutting residential); corner-lot and visibility-triangle rules.
- **Capture:** front / side / rear / street-side; build-to or maximum front setback; increases next to residential districts; buffer widths.
- **Traps:** contextual setbacks ("average of existing buildings within 200 ft, or 20 ft, whichever is less"); footnotes that zero out side setbacks for attached buildings; amendments that changed the formula — always copy exact wording.

## 4. Parking
- **Where:** "Off-street parking and loading" article. Minimum-ratio tables are by **use**, not district; district-specific maximums or exemptions (downtown) sit in the same section.
- **Capture:** ratios for retail, office, restaurant, medical, personal service, hotel, fuel/car wash, plus whatever use the user mentioned; how area is measured (gross vs. net floor area); maximum caps; reductions (parking study %, shared parking, transit, bicycle substitution); EV, ADA (usually building code), bicycle, loading, drive-through stacking.
- **Traps:** "variable" uses requiring a study; rounding rules; multiple uses add together; districts exempt from minimums.

## 5. Lot coverage / intensity
- **Where:** district dimensional table ("max lot coverage", "ground coverage ratio", "max impervious surface", "FAR"); open-space article ("minimum open space %"); landscaping article ("minimum landscaped area %").
- **Capture:** whichever of these exist. If the district table has **no** coverage row, state "No maximum lot/building coverage in the district standards" and list the indirect limits (min open space %, landscaping, buffers, stormwater, setbacks, parking).
- **Traps:** coverage defined as building footprint only vs. all impervious surfaces — quote the definition if it matters.

## Also note (one line each when present)
- Minimum lot area / width / frontage; density for residential/mixed use.
- Design standards: façade materials, glazing, entrances, large-retail standards.
- Landscaping/buffers section; open space; lighting; fences; signs section link.
- Overlay districts that could apply (historic, corridor, airport, flood) — name them and say the user should check the map.
- Approvals/process: site plan review, CUP/SUP board, typical timing if stated.
- Nonconformities: expansion thresholds that trigger full compliance (e.g. "50% floor area increase").

## Accuracy rules
- Quote numbers exactly, with units. Keep "whichever is less/greater" logic intact.
- Every value gets a section citation and link.
- Record the history note (ordinances + dates) for each cited section.
- "Not found" is an acceptable answer; a guessed number is not.
